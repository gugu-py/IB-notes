# 五十头白翁，南北逃世难

——杜甫安史之乱后的诗歌创作

杜甫在安史之乱后创作了大量反映时代动荡和人民疾苦的诗歌。杜甫以沉郁顿挫的笔触，深刻揭示了藩镇割据带来的社会问题，也体现了他对百姓疾苦的深切同情。

### 1. 《三绝句》

l 第一首：“前年渝州杀刺史，今年开州杀刺史。”直接揭露了藩镇割据下地方官员互相开战的乱象。

l 第二首：“群盗相随剧虎狼，食人更肯留妻子。”以“群盗”比喻藩镇军阀的残暴，凶狠超过自然界的野兽。

l 第三首：“殿前兵马虽骁雄，纵暴略与羌浑同。”批评朝廷军队与藩镇军阀一样残暴，天下乌鸦一般黑。

安史之乱后，藩镇割据加剧，地方军阀拥兵自重，战乱频仍，百姓流离失所。杜甫通过这三首绝句，表达了对时局的忧虑和对百姓的同情。

### 2. 《岁晏行》

l “岁云暮矣多北风，潇湘洞庭白雪中。”开篇以寒冬景象渲染悲凉氛围。

l “高马达官厌酒肉，此辈杼轴茅茨空。”对比达官贵人的奢靡与人民的贫苦，可以对比阅读安史之乱前的名句“朱门酒肉臭，路有冻死骨”。

l “况闻处处鬻男女，割慈忍爱还租庸。”描述百姓因赋税被迫卖儿卖女的惨状。

安史之乱后，国家财政困难，赋税沉重，百姓生活困苦。杜甫在诗中描绘了岁末百姓的悲惨生活。

### 3. 《逃难》

l “五十头白翁，南北逃世难。”开篇点明自己年老体衰，无处避难的窘境。

l “疏布缠枯骨，奔走苦不暖。”以极简的笔触描绘了逃难者的饥寒交迫的境遇。

安史之乱后，杜甫和普通百姓一样，因战乱不得不继续四处逃难漂泊。

### 4. 《征夫》

l “十室几人在，千山空自多。”描绘了战乱后十室九空的凄凉景象。

l “路衢唯见哭，城市不闻歌。”控诉战争对市井的破坏。

l “漂梗无安地，衔枚有荷戈。”比喻征夫如浮萍，揭示他们的艰辛和漂泊。

安史之乱后，藩镇割据导致战事依旧不断，百姓被迫从军，杜甫通过这首诗反映了征夫的悲惨命运。

### 5. 《风疾舟中伏枕书怀》

l “故国悲寒望，群云惨岁阴。”以阴云密布的景象象征时局的昏暗与动荡。

l “战血流依旧，军声动至今。”战鼓声延续，战乱仍未结束，百姓依旧流血。

这首诗作于杜甫晚年最后日子，安史之乱虽已结束，但藩镇割据、战乱频仍的局面并未改变。杜甫在诗中既表达了对国家命运的忧虑，也再次抒发了对百姓苦难的深切同情。

## 附录：

1、《三绝句》

其一

前年渝州杀刺史，今年开州杀刺史。群盗相随剧虎狼，食人更肯留妻子。

其二

二十一家同入蜀，唯残一人出洛谷。自说二女啮臂时，回头却向秦云哭。

其三

殿前兵马虽骁雄，纵暴略与羌浑同。闻道杀人汉水上，妇女多在官军中。

2、《岁晏行》

岁云暮矣多北风，潇湘洞庭白雪中。  
渔父天寒网罟冻，莫徭射雁鸣桑弓。  
去年米贵阙军食，今年米贱大伤农。  
高马达官厌酒肉，此辈杼轴茅茨空。  
楚人重鱼不重鸟，汝休枉杀南飞鸿。  
况闻处处鬻男女，割慈忍爱还租庸。  
往日用钱捉私铸，今许铅锡和青铜。  
刻泥为之最易得，好恶不合长相蒙。  
万国城头吹画角，此曲哀怨何时终？

3、《逃难》

五十头白翁，南北逃世难。  
疏布缠枯骨，奔走苦不暖。  
已衰病方入，四海一涂炭。  
乾坤万里内，莫见容身畔。  
妻孥复随我，回首共悲叹。  
故国莽丘墟，邻里各分散。  
归路从此迷，涕尽湘江岸。

4、《征夫》

十室几人在？千山空自多！  
路衢惟见哭，城市不闻歌。  
漂梗无安地，衔枚有荷戈。  
官军未通蜀，吾道竟如何？

5、《风疾舟中伏枕书怀》

节选：

故国悲寒望，群云惨岁阴。  
水乡霾白屋，枫岸叠青岑。  
郁郁冬炎瘴，濛濛雨滞淫。  
鼓迎非祭鬼，弹落似鸮禽。

战血流依旧，军声动至今。
