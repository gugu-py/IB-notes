## Depth via Verbs


### **Causes / Origins**

- **Reveal / Expose** → show underlying problems.
    
- **Trigger / Spark** → immediate causes.
    
- **Generate / Fuel** → long-term pressures.
    
- **Undermine / Erode** → weakening stability.
    

---

### **Consequences**

- **Produce / Result in** → direct outcomes.
    
- **Intensify / Escalate** → worsen tensions.
    
- **Consolidate / Institutionalize** → turn gains into structures.
    
- **Transform / Reshape** → change identity or system.
    

---

### **Change and Continuity**

- **Mark / Represent** → signal turning point.
    
- **Preserve / Maintain** → continuity.
    
- **Break / Depart** → rupture with past practice.
    
- **Adapt / Adjust** → gradual change.
    

---

### **Significance**

- **Demonstrate / Illustrate** → evidence of a bigger trend.
    
- **Symbolize / Embody** → represent values or ideology.
    
- **Legitimize / Justify** → give authority.
    
- **Define / Characterize** → shape movement identity.
    

---

### **Perspective / Evaluation**

- **Contend / Argue** → present stance.
    
- **Criticize / Reject** → opposition.
    
- **Challenge / Question** → undermine assumptions.
    
- **Reinforce / Support** → strengthen a side.
